## Limits

  given; agy prints no declaration list. The executed-step facts (`read_file` with `Path` in the stream and in the
  hook payload; `grep_search` / `list_dir` attempts ending in error) are vendor output.
- One machine (macOS, host A), one model, one day. Whether `excludeDefaultComponents: true` removes `manage_task` on
  1.5.x was not probed. B's profile route was not run.
- `search_web` was not exercised; whether a `search_web`-only research agent can still cite a page is not measured.

The temporary agent file (`~/.gemini/config/agents/triad-probe-tmp.md`) was deleted after each run. Host A's user-level
agy settings already allow `read_url(*)` (R-REVIEW-WEB, the install-time prerequisite); with that allow in place no
page-fetch tool is offered, so the allow does not change the offered set.

Facts this adds:

- `search_web` works with no setting; its result is a search summary with redirect URLs, not a fetched page.
- No page-fetch tool is offered in print mode (`-p`) on 1.5.3, not to a custom agent and not to the default agent.
  `read_url_content` is registry-known but not offered. This matches the official tracker's issue #1353 (open, labelled
  bug, assigned, no workaround; reported on agy 1.4.8): <https://github.com/google-antigravity/antigravity-cli/issues/1353>.
- A custom agent `tools:` list naming a tool the registry does not know aborts the run on 1.5.3 (rc 3, an `error_message`
  step and no model step), so a host never adds an unknown tool name to an agent body as a probe or a fallback.
- `excludeDefaultComponents: true` does not remove `manage_task` on 1.5.3 (the open question in § Limits above),
  matching issue #1015: <https://github.com/google-antigravity/antigravity-cli/issues/1015>.

Official statements (each fetched 2026-11-08): the permissions page names `read_url` as the permission that gates page
reading, default Ask (<https://antigravity.google/docs/permissions>); the SDK tools page says web search and URL fetching
are enabled by default — an SDK statement, not a CLI one (<https://www.antigravity.google/docs/sdk/tools/>).

Limits: one machine, one model, one day. The declared sets in `p2.jsonl` and `p4.jsonl` are the model's report of its
declarations (as in § Limits above). The stream carries no tool output, so the shape of the `search_web` result in
`p1.jsonl` (summary, `Sources:` redirect URLs, no page text, no titles, its first 300 characters quoted) is the model's
report of what the tool returned; the executed `search_web` step and its query, and the abort in `p3.jsonl` / `p3.err`,
are vendor output.
