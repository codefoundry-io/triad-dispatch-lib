do not replace it. C6 is superseded. IDs are not contiguous (C1-C37, C43,
C60-C79), and the maximum ID is not the number of cases.

were inspected statically in the [2026-10-14 audit](../../docs/verification/2026-10-14-spec-contract-audit.md).

canonical static checks. Historical A/B evidence remains attributed to its
original host and snapshot. Native execution, permissions, backend termination,
provider failures and host adoption need independent host evidence.

and [current status and measured verification](../../docs/status.md).
